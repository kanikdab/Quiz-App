# Quiz-App

Приложение Викторина реализовано с использованием HTML, CSS и JavaScript. Это интерактивное приложение предназначено для проверки знаний пользователей с помощью вопросов, включая вопросы с множественным выбором. Оно имеет современный дизайн и удобный интерфейс, который адаптирован для работы как на настольных компьютерах, так и на мобильных устройствах.

При запуске приложения пользователю отображается начальный экран с кнопкой "Начать", нажатие на которую открывает информационное окно с правилами игры. Здесь же можно выбрать продолжение или выход из приложения.

После начала викторины на экране отображается заголовок, таймер, текущий вопрос и варианты ответов. Пользователь выбирает один или несколько из предложенных вариантов и переходит к следующему вопросу, нажав на кнопку "Следующий вопрос".

После прохождения всех вопросов отображается экран результатов с сообщением о завершении викторины и количеством правильных и неправильных ответов. Здесь же доступны кнопки для повторного прохождения викторины или возврата на начальный экран.
